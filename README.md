## 🚀 Featured Project

### 🛒 E-commerce Application

A responsive e-commerce web application featuring product browsing, filtering, shopping cart functionality, user management, and an admin dashboard.

**Key Features**

- 🛍️ Product listing and browsing
- 🔎 Product search and filtering
- 🏷️ Brand and category filters
- 🛒 Shopping cart with LocalStorage persistence
- 👤 User registration and account management
- 🖥️ Admin dashboard for product management
- ➕ Create, ✏️ update, and 🗑️ delete products
- 🔄 API data fetching and mutations
- 📝 Form handling and schema validation
- 📱 Responsive user interface

**Tech Stack**

React · TypeScript · React Router · TanStack Query · Context API · Reducer · React Hook Form · Zod · Axios · Bootstrap · CSS Modules · JSON Server
